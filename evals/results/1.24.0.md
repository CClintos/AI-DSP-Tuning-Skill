one before replying (no tools, no files). This tests the description's
routing; it is not a session with the skill installed.

## Layer 3: agent behaviour

Method: each scenario ran once (the protocol asks for three; a first attempt
at three runs each was cut off by a usage limit and discarded). Each run got
a fresh copy of the `make_fixtures.py` set, the built package unzipped as a
user installs it, and the scenario's scripted replies, to be used only after
the agent had asked the question; with no scripted answer it logged the
question and stopped. Critical failures were checked from the file system
(originals hashed before and after, crossovers of any written tune, plan
contents) and the rubric was graded from each run's real tool calls and log.
An extra scenario B01 covers the borderline Audison prompt. `n/a` marks a
