* Generic in-car target curve (relative dB vs frequency).
* A sensible DEFAULT starting point only -- a downward-tilted "house" curve with
* a bass shelf, similar in spirit to common in-car targets. The tuner anchors the
* overall level automatically, so only the SHAPE matters here.
* Shape: ~+9 dB bass shelf below ~50 Hz easing to flat by 300 Hz, flat 300 Hz-1 kHz
* (the vocal reference), then a steady roll-off to about -5 dB at 10 kHz.
* measure_tilt reads it at about -0.93 dB/oct, inside the -0.8..-1.0 in-car range
* the methodology recommends (the previous default read -0.69: bright/thin).
* Users should feed their OWN curve when they have one (ResoNix, Harman in-car,
* a personal house curve, or flat). Format: "frequency_Hz  level_dB", one per line.
